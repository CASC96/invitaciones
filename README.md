# Lacre Invitaciones

Sitio público de Lacre Invitaciones (GitHub Pages).

- `index.html`: la tienda → https://casc96.github.io/invitaciones/
- Una carpeta por invitación → https://casc96.github.io/invitaciones/NOMBRE-DE-LA-CARPETA/

Para agregar una invitación: descarga el .zip desde el Estudio (pestaña Publicar), descomprímelo y
sube la carpeta aquí (Add file → Upload files).
